
# Симулятор муравья

## Описание проекта

Симулятор муравья — приложение на C# с использованием WPF, демонстрирующее движение муравья по клеточному игровому полю.

Муравей перемещается по клеткам, меняет их цвет и направление движения в зависимости от заданных правил.

## Возможности программы

- Создание игрового поля с заданными размерами.
- Настройка правил поведения на белых и чёрных клетках.
- Автоматический запуск симуляции.
- Приостановка движения.
- Выполнение одного шага вручную.
- Отображение количества выполненных шагов.
- Визуализация положения и направления муравья.

## Используемые технологии

- C#
- WPF
- .NET 10.0
- Visual Studio 2026
- Git и GitHub

## Запуск программы

1. Склонировать репозиторий.
2. Открыть файл AntSimulator.csproj в Visual Studio.
3. Дождаться восстановления зависимостей.
4. Запустить приложение клавишей F5.

## Управление

| Кнопка | Назначение |
|---|---|
| Сгенерировать поле | Создать новое поле |
| Запустить | Начать симуляцию |
| Пауза | Остановить симуляцию |
| Один шаг | Выполнить один шаг муравья |
